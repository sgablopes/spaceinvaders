# Agrion Weather Station

An ESP32-based weather station designed to measure temperature, humidity, rainfall detection, and the electrical signal generated by a DC motor driven by wind. Sensor readings can be accessed over the local network. When the station key is configured, the ESP32 also sends telemetry data to Agrion every 5 seconds.

## Components

| Quantity | Component |
|---:|---|
| 1 | ESP32 DevKit with ESP32-WROOM-32 module |
| 1 kit | FC-37 rain sensor plate and YL-38 module compatible with 3.3 V power supply |
| 1 | Four-pin DHT22 sensor |
| 1 | 5.1 kΩ resistor |
| 1 | Two-wire DC motor |
| 1 set | Propeller and coupling compatible with the motor shaft |
| 1 | Breadboard |
| 1 set | Jumper wires |
| 1 | USB data cable compatible with the DevKit |

## 3D-Printed Parts and Physical Assembly

The AGRION Weather Station incorporates custom 3D-printed parts to support the physical assembly and integration of its electronic components.

These parts include structural supports and mounting elements for the sensors, ESP32, and wind measurement system.

The anemometer uses a wind-driven rotating mechanism connected to a DC motor, which generates an electrical signal used to estimate wind speed.

3D printing enables rapid prototyping, customization, and replacement of mechanical components, making the weather station easier to assemble, maintain, and adapt.

The station combines:

- **Embedded electronics:** ESP32 microcontroller and environmental sensors.
- **3D-printed components:** Structural supports, mounting parts, and anemometer assembly.
- **Environmental monitoring:** Temperature, humidity, rainfall detection, and estimated wind speed.
- **IoT connectivity:** Local sensor readings and periodic telemetry transmission to the AGRION platform.

The 3D models, assembly references, and photographs of the physical prototype are available in the project's documentation.

**Note:** Wind speed measurements are currently based on a preliminary bench-test calibration and should not be interpreted as certified meteorological measurements.

## Assembly

Use the [wiring diagram](Diagrama_ESP32_Sensores_Motor.png) to assemble the circuit while the ESP32 is powered off.

| Component | Terminal | Connection |
|---|---|---|
| FC-37 | Two terminals | Two-pin connector on the YL-38 |
| YL-38 | `VCC` / `GND` | ESP32 `3V3` / `GND` |
| YL-38 | `D0` | `GPIO26` |
| YL-38 | `A0` | Not connected |
| DHT22 | Pin 1 `VDD` / Pin 4 `GND` | ESP32 `3V3` / `GND` |
| DHT22 | Pin 2 `DATA` | `GPIO27` |
| DHT22 | Pin 3 `NC` | Not connected |
| 5.1 kΩ resistor | Two terminals | One connected to `DATA`, the other to `3V3` |
| DC motor | Positive terminal in the propeller rotation direction / negative terminal | ESP32 `GPIO35` / `GND` |

Before connecting the motor, verify its polarity and the voltage it generates in the propeller's rotation direction. During testing, keep the ESP32 powered on and ensure that the signal at **GPIO35 remains between 0 and 3.1 V**, including voltage peaks.

[ESP32 ADC Reference](https://docs.espressif.com/projects/arduino-esp32/en/latest/api/adc.html)

## Arduino IDE Setup

1. Install the **Arduino IDE** and the **esp32 board package by Espressif Systems**. [ESP32 Board Package Installation](https://docs.espressif.com/projects/arduino-esp32/en/latest/installing.html)
2. In the Library Manager, install **DHT sensor library** and **Adafruit Unified Sensor**, both developed by Adafruit. [DHT Library Installation](https://learn.adafruit.com/dht/using-a-dhtxx-sensor-with-arduino)
3. Open [EstacaoESP32.ino](EstacaoESP32/EstacaoESP32.ino), select **ESP32 Dev Module**, and choose the board's serial port under **Tools**. Set **Upload Speed** to **115200**.

## Configuration and Firmware Upload

1. To send data to Agrion, enter the station key in `AGRION_STATION_KEY`. The configured station identifier is `agrion-demo-001`. Leave the key empty if you only want to access readings locally.
2. Connect the DevKit via USB and click **Upload** in the Arduino IDE.
3. After uploading, open the **Serial Monitor at 115200 baud** and select **Newline**.
4. During the initial setup, enter the **SSID** of a **2.4 GHz Wi-Fi network** and provide the password when prompted. To change a previously saved network, enter `wifi` in the Serial Monitor.
5. Once connected, the ESP32 displays the address `GET http://<ESP32_IP>/sensores`.

## Local Sensor Readings

Open the displayed address on a device connected to the same network. In PowerShell, replace the example IP address with the ESP32's actual IP address.

```powershell
Invoke-RestMethod -Uri "http://192.168.1.42/sensores" | ConvertTo-Json
```

```json
{
  "temperatura_c": 24.6,
  "umidade_relativa_pct": 61.2,
  "chuva_detectada": true,
  "yl38_d0": 0,
  "motor_adc_raw": 450.0,
  "vento_estimado_m_s": 4.0
}
```

Each request reads the rain sensor and calculates the average of 64 ADC samples from the motor. The DHT22 requires a minimum interval of 2 seconds between reading attempts. When the DHT22 is unavailable, its corresponding fields return `null` in the local response.

The Serial Monitor displays the ADC count and estimated wind speed every second, even without a Wi-Fi connection.

The bench-test calibration uses **450 ADC counts as the reference for 4.0 m/s**, maintaining the same proportional relationship above this reference point.

## Sending Telemetry to Agrion

With the station key configured, connect the ESP32 to a network with internet access. The board synchronizes its clock to validate the HTTPS certificate and sends a POST request every **5 seconds** to the [telemetry endpoint](https://agrion.earth/api/v1/stations/telemetry).

```http
Content-Type: application/json
X-Station-Key: <station-key>
```

```json
{
  "station_id": "agrion-demo-001",
  "measurements": {
    "temperature_c": 24.6,
    "humidity_pct": 61.2,
    "rain_detected": true,
    "yl38_d0": 0,
    "motor_adc_raw": 450.0,
    "vento_estimado_m_s": 4.0,
    "wind_voltage_mv": 454
  }
}
```

`wind_voltage_mv` represents the average voltage measured directly at GPIO35, expressed in millivolts. The bench-calibrated wind speed estimate is provided in `vento_estimado_m_s`.

If temperature or humidity readings are unavailable, the corresponding field is omitted from the POST request. The server records the timestamp when the telemetry data is received.

The message **`Agrion: HTTP 201.`** indicates that the server has successfully accepted the data packet.

The POST request runs in a separate task. If transmission fails, the ESP32 automatically retries during the next cycle when Wi-Fi connectivity is available.
